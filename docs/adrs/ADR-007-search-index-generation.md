# ADR-007: Search Index Generation and Invalidation

**Status:** Decided
**Date:** 2026-08-08
**Depends on:** Technical Architecture §15, Backlog E09

---

## Context

V1 search must serve public results without exposing private data. Private dashboard search uses D1 directly.

## Decision

**V1 public search:** Static JSON index generated on publish/unpublish.

- Format: Pageable JSON file(s) served as CDN assets (not R2 signed)
- Generated by a queue job triggered by publish/unpublish
- Contains only public approved fields (title, summary, slug, type, date)
- Index is replaced atomically — old index served until new is ready
- Unpublish triggers index regeneration and removes the entity's entry

**V1 private dashboard search:** Authenticated D1 full-text queries through /api/v1/search endpoint.

- Query limited to owner's entities by authorization context
- Rate-limited to prevent D1 abuse
- Never exposes private counts or existence to unauthenticated callers

## Consequences

- Public search never reveals private matches, counts or existence
- V3 semantic search adds embeddings without changing this base architecture
- Search index generation failure retains last successful index
